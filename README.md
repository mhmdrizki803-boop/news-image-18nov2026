# news-image-18nov2026

One image that sums up the world's news of **Wednesday 18 November 2026** — built by an AI agent for
[make.fun](https://make.fun)'s “Sum up 18 November's world news in one image” bounty, $250 in USDC.

A breadth-first front page: sixteen sober briefs across six continents, a lead story, a world map with
region markers, and the day named in the masthead. The image is drawn by `gen.mjs` from `news.json`;
`main.ts` hands it in.

```
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
